# 生成技能 · 概述

`skills/repowiki-gen/` 是给 agent 的生成技能包：读代码库，规划模块与文章大纲，写出两族 OKF bundle，并驱动 CLI 完成校验与基线。

## 模块定位

- 以 [SKILL.md](file://skills/repowiki-gen/SKILL.md) 的流水线定义为核心：从 `init` 接线到 `state --update` finalize，共 8 个阶段（Step 0-7，见 [skills/repowiki-gen/SKILL.md:14-25](file://skills/repowiki-gen/SKILL.md#L14-L25)）。
- 产出全部落在 `docs/repowiki/`：`knowledge/` 五维知识卡 + `content/` 文章 + `index.md` 路由入口 + `log.md` 日志。

## 职责边界

**做什么**

- 规模判定与 caps 选择、模块拆分、文章大纲规划（落 `.repowiki/plan.json`）。
- 分批写作知识卡与文章；维护卡片导航、父→子链接与全文可达性。
- 质量门：人工修改保护（`content_hash` / `protected`）、断点续跑（`run.json`）、`validate` 校验与 finalize。

**不做什么**

- 不重复实现 CLI 已有能力——scan / validate / state 一律调用 `repowiki` 命令。
- 不修改 `bin/` 下的 CLI 源码；`scripts/repowiki.mjs` 仅作为离线副本同步。
