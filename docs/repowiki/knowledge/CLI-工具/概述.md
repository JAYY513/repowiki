# CLI 工具 · 概述

`bin/repowiki.mjs` 是 repowiki 的全部机器侧实现：扫描仓库、校验知识库、维护新鲜度基线。写入侧与读取侧的一切自动动作都由它执行。

## 模块定位

- 单文件 Node.js CLI（ESM、零第三方依赖），提供 `init` / `scan` / `state` / `status` / `validate` 五个子命令；命令入口见 [bin/repowiki.mjs:1590-1649](file://bin/repowiki.mjs#L1590-L1649)。
- `main()` 分发子命令，按退出码结束进程；`state --update` 写入页面→源码与引注索引，`status --json` 报告页面重生成范围和行号复核候选（[bin/repowiki.mjs:886-904](file://bin/repowiki.mjs#L886-L904)、[bin/repowiki.mjs:1099-1115](file://bin/repowiki.mjs#L1099-L1115)）。
- 免安装可用（`node bin/repowiki.mjs <cmd>`）；也可经 `bin` 映射全局安装后以 `repowiki <cmd>` 运行。

## 职责边界

**做什么**

- `init` 接线；`scan` 生成快照；`state` 维护 `.repowiki/state.json` 基线；`status` 比对 HEAD 并报告 `affected_pages`，有引注索引时另给出行号复核候选；`validate` 校验 OKF bundle（[bin/repowiki.mjs:886-904](file://bin/repowiki.mjs#L886-L904)、[bin/repowiki.mjs:1099-1115](file://bin/repowiki.mjs#L1099-L1115)）。
- 安全扫描：跳过密钥类文件与超过 1 MB 的大文件，强制排除 `docs/repowiki/` 与 `.repowiki/`（[bin/repowiki.mjs:313-334](file://bin/repowiki.mjs#L313-L334)）。

**不做什么**

- 不生成 wiki 内容——模块规划与页面写作由 `repowiki-gen` 技能驱动 agent 完成。
- 不做网络访问；除 `AGENTS.md`、`.repowiki/` 与 `docs/repowiki/` 外不改动仓库。
