## 关键流程

- **scan**：合并 ignore 规则、遍历文本文件并记录 SHA-256，写入 `.repowiki/snapshot.json`（[bin/repowiki.mjs:458-573](file://bin/repowiki.mjs#L458-L573)）。
- **state --update**：按 plan 建立页面→源码映射，解析 Markdown 中的 `file://…#L…` 引注并存入 state；索引以 `citation_index_version: 1` 标识（[bin/repowiki.mjs:789-821](file://bin/repowiki.mjs#L789-L821)、[bin/repowiki.mjs:886-904](file://bin/repowiki.mjs#L886-L904)）。
- **status**：比对基线与 HEAD，glob 匹配产生 `affected_pages`；可用索引时再按零上下文 diff 标出引用重叠或行号偏移候选（[bin/repowiki.mjs:1035-1137](file://bin/repowiki.mjs#L1035-L1137)）。候选只辅助锚点核查，不代表语义影响全集。
- **validate**：检查 frontmatter、目录约定、链接可达性与 plan 一致性（[bin/repowiki.mjs:1141-1443](file://bin/repowiki.mjs#L1141-L1443)）。

## 依赖关系

- 文件系统：读写 `.repowiki/`（snapshot / state / plan / run）与 `docs/repowiki/`，注入 `AGENTS.md`。
- git CLI：经 `execSync` 调用 `rev-parse` / `diff` / `rev-list`；所有调用包在 try/catch 中，失败时降级为空基线而不是崩溃。
