# 生成技能

## 概述 <!-- category:overview -->

`skills/repowiki-gen/` 是给 agent 的生成技能包：读代码库，规划模块与文章大纲，写出两族 OKF bundle，并驱动 CLI 完成校验与基线。

**做什么**

- 规模判定与 caps 选择、模块拆分、文章大纲规划（落 `.repowiki/plan.json`）。
- 分批写作模块文件与文章；维护模块互引、父→子链接与全文可达性。
- 质量门：人工修改保护（`content_hash` / `protected`）、断点续跑（`run.json`）、`validate` 校验与 finalize。

**不做什么**

- 不重复实现 CLI 已有能力——scan / validate / state 一律调用 `repowiki` 命令。
- 不修改 `bin/` 下的 CLI 源码；`scripts/repowiki.mjs` 仅作为离线副本同步。

## 架构设计 <!-- category:architecture_design -->

### 内部结构

三段式，各司其职：

| 组成 | 文件 | 职责 |
|---|---|---|
| 流程指令 | `SKILL.md` | 8 阶段流水线、caps 表、plan v2 约定、4a/4b 生成步骤、质量门 |
| 写作规范 | `references/output-spec.md` | 目录组织、frontmatter、模块文件与文章原型、命名与链接纪律 |
| 阶段细节 | `references/pipeline.md` | budget 评估、模块树规划、知识合成、大纲与写作、校验规则 |
| CLI 副本 | `scripts/repowiki.mjs` | 与 `bin/repowiki.mjs` 逐字节一致的离线兜底（当前两者 SHA-256 相同） |

### 关键流程

执行者分工（[skills/repowiki-gen/SKILL.md:16-25](file://skills/repowiki-gen/SKILL.md#L16-L25)）：

- **CLI 执行**：Step 0 wire（`init`）、Step 1 scan、Step 6 validate、Step 7 finalize（`state --update`）。
- **agent 执行**：Step 2 budget、Step 3 plan、Step 4 generate（4a 模块文件 → 4b 文章，自底向上）、Step 5 link。
- 增量模式：`status --json` 的 `affected_pages` 决定重生成范围——命中模块文件、相关文章及其祖先（[skills/repowiki-gen/SKILL.md:132-136](file://skills/repowiki-gen/SKILL.md#L132-L136)）。

### 依赖关系

- 运行时依赖 `repowiki` CLI（优先 `bin/`，缺失时用 `scripts/` 副本）与 git。
- 产物供读取侧消费：`AGENTS.md` 接线声明 `docs/repowiki/` 为知识源，阅读 agent 按页面 `triggers` 命中加载。
- 双副本纪律：修改 CLI 后必须同步 `bin/` 与 `scripts/` 两份拷贝，保持逐字节一致。
