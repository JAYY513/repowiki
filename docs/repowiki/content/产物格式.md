## 领域模型

`docs/repowiki/` 是一个 OKF bundle：以 [index.md](../index.md) 为唯一路由入口的 Markdown 页面集，按两族组织（[skills/repowiki-gen/references/output-spec.md:6-28](file://skills/repowiki-gen/references/output-spec.md#L6-L28)）：

```
docs/repowiki/
├── index.md              路由入口：模块清单 + 文章清单
├── knowledge/<模块名>/    五维知识卡（概述.md 为锚文档）
├── content/              文章（overview / getting_started / domain / deep_dive / developer_guide）
├── meta/                 预留：行级引用登记（暂不落盘）
└── log.md                生成日志（finalize 写入）
```

## 核心概念

| 概念 | 含义 |
|---|---|
| 两族 | `knowledge/` 面向「模块 × 维度」精确命中；`content/` 面向叙事阅读 |
| 五维知识卡 | 概述 / 架构设计 / 技术栈 / 编码规范 / 特殊配置与命令；`dimension` 字段语言无关，validate 的目录锚依赖它 |
| 五类文章 | overview / getting_started / domain / deep_dive / developer_guide，各有章节模板（[skills/repowiki-gen/references/output-spec.md:142-150](file://skills/repowiki-gen/references/output-spec.md#L142-L150)） |
| `triggers` | 页面的任务意图列表——读取侧命中即加载（route-before-body） |
| 引注与图表来源 | 文首 `<cite>` 列引用文件；源码结论带行号锚；Mermaid 图后附图表来源 |

## 关键流程

生成（技能自底向上写作）→ `repowiki validate` 校验（frontmatter、目录约定、链接可达性、plan 一致性，[bin/repowiki.mjs:952-1219](file://bin/repowiki.mjs#L952-L1219)）→ `repowiki state --update` 落基线（页面→源映射 + `content_hash`，[bin/repowiki.mjs:696-769](file://bin/repowiki.mjs#L696-L769)）。

## 模块边界

- 两族职责不重叠：知识卡回答「某模块的某类知识」，文章写叙事与跨模块综合；同一知识不在两族重复（[skills/repowiki-gen/references/output-spec.md:26-28](file://skills/repowiki-gen/references/output-spec.md#L26-28)）。
- 模块关系不进正文：每模块目录的 `_module.yaml` 记录 `scope` / `source_files` / `depends_on` / `related_to` / `children`；`meta/` 为行级引用登记预留，当前不创建空目录；`index.md` / `log.md` 为保留名。

## 新鲜度与保护

- 基线：`state.json` 记录 git 基线与每页 `content_hash`；`repowiki status` 三态 fresh（0）/ stale（10）/ missing（11），`stale` 时输出 `affected_pages` 驱动增量重生成（[bin/repowiki.mjs:904-918](file://bin/repowiki.mjs#L904-L918)）。
- 人工保护：生成前逐页比对 `content_hash`，手改页面默认跳过；`protected: true` 永久锁定（[skills/repowiki-gen/SKILL.md:185-190](file://skills/repowiki-gen/SKILL.md#L185-L190)）。
- 断点续跑：分批检查点写入 `run.json`，finalize 成功后删除（[skills/repowiki-gen/SKILL.md:204-208](file://skills/repowiki-gen/SKILL.md#L204-L208)）。
