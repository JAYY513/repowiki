## 领域模型

`docs/repowiki/` 是一个 OKF bundle：以 [index.md](../index.md) 为唯一路由入口的 Markdown 页面集，按两族组织（[skills/repowiki-gen/references/output-spec.md:6-28](file://skills/repowiki-gen/references/output-spec.md#L6-L28)）：

```
docs/repowiki/
├── index.md              路由入口：模块清单 + 文章清单
├── knowledge/<模块名>/    五维知识卡（概述.md 为锚文档）
├── content/              文章（overview / getting_started / domain / deep_dive / developer_guide）
├── meta/                 预留：行级引用登记（暂不落盘）
└── log.md                生成日志（finalize 写入）
```

## 核心概念

| 概念 | 含义 |
|---|---|
| 两族 | `knowledge/` 面向「模块 × 维度」精确命中；`content/` 面向叙事阅读 |
| 五维知识卡 | 概述 / 架构设计 / 技术栈 / 编码规范 / 特殊配置与命令；`dimension` 字段语言无关，validate 的目录锚依赖它 |
| 五类文章 | overview / getting_started / domain / deep_dive / developer_guide，各有章节模板（[skills/repowiki-gen/references/output-spec.md:142-150](file://skills/repowiki-gen/references/output-spec.md#L142-L150)） |
| `triggers` | 页面的任务意图列表——读取侧命中即加载（route-before-body） |
| 引注与图表来源 | 文首 `<cite>` 列引用文件；源码结论带行号锚；Mermaid 图后附图表来源 |

## 关键流程

生成（技能按 plan 增量写作）→ `repowiki validate` 校验 bundle（[bin/repowiki.mjs:1141-1443](file://bin/repowiki.mjs#L1141-L1443)）→ `repowiki state --update` 保存页面源码范围、`content_hash` 与 Markdown 行号引注索引（[bin/repowiki.mjs:789-821](file://bin/repowiki.mjs#L789-L821)、[bin/repowiki.mjs:886-904](file://bin/repowiki.mjs#L886-L904)）。

## 模块边界

- 两族职责不重叠：知识卡回答「某模块的某类知识」，文章写叙事与跨模块综合；同一知识不在两族重复（[skills/repowiki-gen/references/output-spec.md:26-28](file://skills/repowiki-gen/references/output-spec.md#L26-28)）。
- 模块关系不进正文：每模块目录的 `_module.yaml` 记录 `scope` / `source_files` / `depends_on` / `related_to` / `children`；bundle 内 `meta/` 仍为预留，运行时行号引注索引单独保存在 `.repowiki/state.json`（[bin/repowiki.mjs:815-819](file://bin/repowiki.mjs#L815-L819)）；`index.md` / `log.md` 为保留名。

## 新鲜度与保护

- 基线：`state.json` 记录 git commit、页面源码范围、`content_hash` 和版本化的行号引注索引；`status` 用源码变更产生 `affected_pages`，可用索引时额外给出行号复核候选（[bin/repowiki.mjs:815-819](file://bin/repowiki.mjs#L815-L819)、[bin/repowiki.mjs:886-904](file://bin/repowiki.mjs#L886-L904)、[bin/repowiki.mjs:1099-1115](file://bin/repowiki.mjs#L1099-L1115)）。
- 引注候选只定位行号重叠或偏移；未被标出的引用不代表语义无影响，`affected_pages` 才是唯一重生成依据（[skills/repowiki-gen/SKILL.md:141-145](file://skills/repowiki-gen/SKILL.md#L141-L145)）。
- 人工保护：生成前逐页比对 `content_hash`，手改页面默认跳过；`protected: true` 永久锁定（[skills/repowiki-gen/SKILL.md:151-154](file://skills/repowiki-gen/SKILL.md#L151-L154)）。
- 断点续跑：分批检查点写入 `run.json`，finalize 成功后删除（[skills/repowiki-gen/SKILL.md:146-149](file://skills/repowiki-gen/SKILL.md#L146-L149)）。
