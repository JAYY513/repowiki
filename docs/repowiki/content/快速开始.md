## 接线与扫描

```bash
repowiki init    # AGENTS.md 接线 + state 基线（幂等）
repowiki scan    # 快照：文件、哈希、语言分布 → .repowiki/snapshot.json
```

`init` 向 `AGENTS.md` 注入管理块（读取纪律 + 源声明）；若已有手写 `## repowiki` 分区，仅补声明行、其余逐字保留（[README.md:99-121](file://README.md#L99-L121)）。

## 生成 wiki

让 agent 运行 `/repowiki-gen`（或说「生成 repowiki」）。技能驱动完整流水线：scan → plan → generate → validate → baseline（[README.md:87-89](file://README.md#L87-L89)），产出 `docs/repowiki/` 下的两族 bundle——结构见[产物格式](产物格式.md)。

## 保持新鲜

```bash
repowiki status   # 0 = 新鲜 · 10 = 过期 · 11 = 缺失
```

新提交后退出码 `10` 表示 wiki 描述的是旧提交，重跑 `/repowiki-gen` 即可（[README.md:91-97](file://README.md#L91-L97)）。

## 典型工作流

1. 改动代码 → 提交前运行 `repowiki status` 自查（AGENTS.md 的 Wiki 纪律：[AGENTS.md:7-10](file://AGENTS.md#L7-L10)）。
2. 退出码 `10` → 重跑 `/repowiki-gen` 做增量更新。
3. 收尾再跑 `repowiki status`，确认 `fresh` 后提交。
